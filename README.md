# Insights Agent 🧠

An AI-powered content strategy generator built with Streamlit and Pipedream that automatically analyzes social media niches, extracts viral hooks, and stores actionable insights.

## Features
* **Automated Workflow Trigger:** Sends targeted niche keywords directly to a Pipedream webhook backend.
* **Real-Time Status Tracking:** Visualizes multi-stage processing including Instagram Reels scraping and psychological pattern analysis.
* **Dynamic Data Sync:** Automatically pulls and displays the latest strategy results via a connected Google Sheets CSV database.
* **Minimalist Dark Mode UI:** Custom-styled dashboard optimized for clean, professional data presentation.

## Tech Stack
* **Frontend:** Streamlit, Pandas, Custom CSS
* **Backend & Automation:** Pipedream Webhooks, Requests
* **Data Source:** Google Sheets (CSV Export)
